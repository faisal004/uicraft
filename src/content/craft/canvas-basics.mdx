## How canvas works

Canvas is an HTML element with a drawing surface inside it. Think of it as a sheet of graph paper. Unlike a `<div>` or `<p>`, the shapes you draw are not separate HTML elements. The browser stores their colors as pixels in one image.

### Step 1. Put a blank canvas on the page

The `width` and `height` attributes make a drawing grid that is 600 pixels wide and 300 pixels tall. Its top-left corner is `(0, 0)`. Moving right increases **x**; moving down increases **y**. The grid lines in the live example are just a guide we draw on that surface.

```tsx
<canvas width={600} height={300}>
  Your browser does not support canvas.
</canvas>
```

<CanvasBasicsStep step="0" />

**Try this:** find `(0, 0)` in the upper-left corner. The right edge is near `x = 600`, and the bottom edge is near `y = 300`.

### Step 2. Get the 2D drawing tool and draw a rectangle

The canvas element is the paper. `getContext("2d")` gives us the drawing tool. Set `fillStyle` to a color, then call `fillRect(x, y, width, height)`. This rectangle starts 50 pixels from the left and 65 pixels from the top.

```ts
const canvas = canvasRef.current
const context = canvas?.getContext("2d")
if (!context) return

context.fillStyle = "#2563eb"
context.fillRect(50, 65, 180, 100)
```

<CanvasBasicsStep step="1" />

**Try this:** read the grid behind the blue rectangle. Its left edge is at `x = 50`, its top is at `y = 65`, and it spans 180 by 100 pixels.

### Step 3. Make a path to draw a circle

Canvas has no `circle` HTML tag. Start a path, describe a circle with `arc`, then fill it. The first two numbers are its center. The third is its radius. Angles are in radians: `0` to `Math.PI * 2` makes one full turn.

```ts
context.beginPath()
context.arc(430, 115, 50, 0, Math.PI * 2)
context.fillStyle = "#f59e0b"
context.fill()
```

<CanvasBasicsStep step="2" />

**Try this:** the orange circle's center is at `(430, 115)`. Its radius is 50 pixels, so it reaches from `x = 380` to `x = 480`.

### Step 4. Draw text onto the pixels

Set a font, choose a color, and use `fillText(text, x, y)`. The `y` value is the text's **baseline**, where letters sit, rather than its top edge. This text is drawn into the canvas image; it is not a selectable HTML heading.

```ts
context.fillStyle = "#0f172a"
context.font = "bold 44px Arial"
context.fillText("Hello, canvas!", 150, 242)
```

<CanvasBasicsStep step="3" />

**Try this:** compare the canvas text with an ordinary page heading. Both can look similar, but only the HTML heading remains a real text element.

### Step 5. Clear and redraw to make animation

Canvas keeps what you draw until you clear or cover it. An animation therefore repeats three actions: clear the old frame, draw at a new position, and ask the browser for the next frame. `requestAnimationFrame` supplies a time value. We use it to move the circle smoothly.

```ts
function draw(time: number) {
  context.clearRect(0, 0, 600, 300)
  const x = 80 + (Math.sin((time - started) / 700) + 1) * 200
  context.beginPath()
  context.arc(x, 150, 34, 0, Math.PI * 2)
  context.fill()
  frame = requestAnimationFrame(draw)
}

const started = performance.now()
frame = requestAnimationFrame(draw)
// On cleanup: cancelAnimationFrame(frame)
```

<CanvasBasicsStep step="4" />

**Try this:** imagine leaving out `clearRect`. You would see a trail of every old circle instead of one moving circle.

### Step 6. Read pixels back from a canvas

This is the bridge to particle effects. Draw `HELLO` into a second canvas that stays offscreen. `getImageData` returns four numbers for each pixel: red, green, blue, and alpha. **Alpha** says how opaque the pixel is. If alpha is above 128, that pixel belongs to a visible part of the letters, so we draw a small blue square at the same position on the visible canvas.

```ts
const mask = document.createElement("canvas")
mask.width = 600
mask.height = 300
const pen = mask.getContext("2d")!
pen.font = "bold 110px Arial"
pen.textAlign = "center"
pen.textBaseline = "middle"
pen.fillText("HELLO", 300, 150)

const pixels = pen.getImageData(0, 0, 600, 300).data
context.fillStyle = "#2563eb"
for (let y = 0; y < 300; y += 5) {
  for (let x = 0; x < 600; x += 5) {
    const alpha = pixels[(y * 600 + x) * 4 + 3]
    if (alpha > 128) context.fillRect(x, y, 3, 3)
  }
}
```

<CanvasBasicsStep step="5" />

**Try this:** the letters are now made of little squares. The `5` in each loop controls how far apart we sample: make it smaller for denser dots, or larger for fewer dots.

Once this feels clear, [Text to Particles](/craft/text-to-particles) adds movement to sampled text pixels. [Thanos Snap](/craft/thanos-snap) uses pixel masks to hide and animate copies of ordinary HTML.
